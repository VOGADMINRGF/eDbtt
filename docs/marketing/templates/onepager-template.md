# eDebatte Onepager — Vorlage

Status: `template`

## Format

- bevorzugt: A4 hoch oder 16:9 als digitale Einzelseite
- eine Zielgruppe
- eine Kernbotschaft
- ein primärer CTA
- reale UI, freigegebene Voxy-Assets und maximal ein unterstützendes Diagramm

## Aufbau

### 1. Hero

**Headline:**

> [Konkreter Nutzen für die Zielgruppe]

**Subline:**

> [Wie eDebatte Content, Quellen, Perspektiven und Beteiligung nachvollziehbar verbindet]

**Visual:**

- passende Voxy-Variante
- reale Produktoberfläche oder klar gekennzeichnetes Konzept

### 2. Das Problem

Drei beobachtbare Probleme, keine allgemeinen Marketingfloskeln.

- [Problem 1]
- [Problem 2]
- [Problem 3]

### 3. Was eDebatte anders macht

```text
Input / Entwicklung
→ Quellen und Perspektiven
→ Debattenstand / Dossier
→ Review und Beteiligung
→ nachvollziehbares Ergebnis
```

### 4. Nutzen

- [funktionaler Nutzen]
- [Zeit-/Qualitätsnutzen ohne unbelegte Zahl]
- [Transparenz-/Vertrauensnutzen]
- [Mehrsprachigkeits- oder Community-Nutzen]

### 5. Vertrauensregeln

- kein Auto-Publish
- KI bleibt Guide, nicht Entscheidungsersatz
- Quellen, Gegenpositionen und offene Fragen bleiben sichtbar
- Partnerstatus erzeugt keine inhaltlichen Sonderrechte
- Original- und Lesesprache bleiben getrennt

Nur die für die Zielgruppe relevanten Punkte verwenden.

### 6. Anwendungsfall

Ein konkreter Workflow mit 3–5 Schritten.

### 7. CTA

> [Ein realer nächster Schritt]

- reale Route oder Kontaktweg
- keine zweite CTA-Ebene

## Footer

- eDebatte-Wordmark aus kanonischem Asset
- optional VoiceOpenGov-Zuordnung, wenn inhaltlich erforderlich
- Quellen-/Statushinweis
- Version und Freigabestatus

## Review

- [ ] Zielgruppe eindeutig
- [ ] Produktwahrheit belegt
- [ ] keine Fake-Zahlen oder -Partner
- [ ] Voxy korrekt verwendet
- [ ] CTA real
- [ ] mobil und gedruckt lesbar
- [ ] sprachlich und fachlich freigegeben
