# Feed -> Anlassraum -> Dossier -> Output Model

## 1. Problem des alten Feed-Ansatzes

Feed-first erzeugt:
- Rauschen
- Dubletten
- fragmentierte Themen
- Leerlauf im Admin

Das Muster:
Feed -> Analyze -> Publish
ist fuer eDebatte ungeeignet.

## 2. Neues Zielmodell

Signal -> Anlassraum -> Dossier -> Runde / Embed / Event / Funding / Monitoring

## 3. Rolle der Feeds

Feeds sind nur Signalquellen.
Sie duerfen:
- Anlassraum-Vorschlaege liefern
- bestehende Anlassraeume mit Material speisen
- Trigger fuer Review sein

Feeds duerfen nicht:
- direkt publizieren
- direkt Dossiers live schalten
- Wahrheit erzeugen

## 4. Feed Review Queue

Empfohlene Aktionen:
- ignore
- attach_to_anlassraum
- create_anlassraum_candidate
- mark_as_weak_signal

## 5. Anlassraum als Sammelraum

Der Anlassraum nimmt auf:
- Feed-Signale
- Community Inputs
- Events / QR-Fragen
- Hinweise
- Journalistische Ausloeser
- Offizielle Dokumente

## 6. Dossier als Analyseakte

Das Dossier ordnet:
- Claims
- Quellen
- Widersprueche
- Optionen
- Eventualitaeten
- Konsequenzen

## 7. Outputs

Aus Anlassraum / Dossier koennen spaeter entstehen:
- Runde
- Event-Board
- Embed / QR Companion
- Funding Case
- Monitoring-Raum
