# Part 18 – Signals & Funding Model

## 1. Core Principle

**Signals zeigen Relevanz. Funding ermoeglicht Umsetzung.**

Das System trennt strikt:
1. Signals (internes Relevanzsystem)
2. Funding (Geld / Ressourcen / Mission / Projekt)

## 2. Duales System

### 2.1 Signals
Signals sind:
- intern
- nicht monetarisiert im Sinn von „Kauf = Wahrheit“
- nicht abstimmungswirksam
- nur Prioritaets- und Relevanzindikatoren

### 2.2 Funding
Funding ist:
- Geld
- Ressourcen
- Umsetzung
- Beschleunigung / Ermöglichung
- transparent, aber ohne inhaltliche Kaufwirkung

## 3. Funding-Typen

### 3.1 Mission Funding
Zweck:
- Sache / Bewegung / allgemeines Thema unterstuetzen
- keine harte Zielsumme erforderlich

Beispiel:
- Direkte Demokratie
- kommunale gesellschaftliche Verantwortung
- Transparenz / Aufklaerung

Typischer Plattformanteil:
- 10–20 %

### 3.2 Projekt Funding
Zweck:
- klares Projekt, klares Ziel, klares Budget

Beispiel:
- Spielplatz-Restaurierung
- neues Nachbarschaftsprojekt
- konkrete Umsetzung nach Dossier / Anlassraum

Typischer Plattformanteil:
- 5–10 %

### 3.3 Ressourcen Funding
Zweck:
- Sachspenden
- Material
- Arbeitsstunden
- Kontakte
- Handwerker / Know-how

Beispiel:
- Sichtzaun fuer Kita
- Holz / Zaunmaterial
- Freiwilligeneinsatz
- Werkzeug / Planung

Monetarisierung:
- indirekt / servicebasiert / optional Vermittlungsgebuehr
- nicht primär wie Geldfunding behandeln

### 3.4 Hybrid Funding
Kombination aus:
- Geld
- Ressourcen
- Mission / Projektanteilen

## 4. Funding Intent vor Funding

Vor einem Funding-Start sollte moeglichst zuerst Intent gemessen werden.

Beispiel:
- „Wuerden Sie dieses Projekt unterstuetzen?“
- „Mit welchem Betrag / welcher Ressourcenart waeren Sie grundsaetzlich dabei?“

Ziel:
- keine leeren Fundings
- bessere Conversion
- bessere Projektwahl

## 5. Readiness Score

Funding-Readiness kann abgeleitet werden aus:
- SignalScore
- Funding Intent
- Klarheit des Ziels
- Stakeholderlage
- vorhandenen Quellen / Dossier-Reife
- Konfliktgrad

## 6. Funding Lifecycle

Empfohlene Status:
- `draft`
- `intent_only`
- `ready`
- `live`
- `completed`
- `impact_tracking`
- `closed`
- `canceled`

## 7. Preconditions

Funding darf nur starten, wenn mindestens:
- Anlassraum.status >= `reviewed`
- ausreichend Relevanz / Signals vorhanden
- Funding Intent oder vergleichbare Plausibilisierung vorhanden
- klarer Zweck definiert ist

## 8. Matching Funds

Institutionen / Organisationen koennen sagen:
- „Wir verdoppeln jede Spende bis 5.000 EUR“
- „Wir matchen Material oder Arbeitsstunden“

Wichtig:
- sichtbar und transparent
- nie als inhaltliche Einflussnahme
- nur fuer Motivation / Umsetzung

## 9. Anti-Capture Regeln

- max. Anteil eines Akteurs an Funding begrenzen (z. B. 20 %)
- grosse Betraege markieren
- Transparenz fuer Top-Funder
- Funding niemals mit Wahrheits- oder Moderationshoheit verknuepfen

## 10. Impact Tracking

Nach Funding:
- Fortschritt sichtbar machen
- Ergebnisse dokumentieren
- Bilder / Nachweise / Status
- Folgeprojekte oder Wartung anschliessen

## 11. Re-Funding / Folgeprojekte

Nach einer Umsetzung kann:
- Wartung
- Erweiterung
- zweites Projekt
als Folgeprojekt gestartet werden

## 12. Failure Handling

- Funding erreicht Ziel nicht -> schließen / neu aufsetzen
- Ziel unklar -> zurueck in Intent / Review
- Konflikt um Mittelverwendung -> Moderator / Review / Dossier-Hinweis
- zu grosser Einfluss einzelner Akteure -> markieren / begrenzen

## 13. Verbindung zu Community und VoiceOpenGov

Funding erfuellt mehrere Funktionen:
1. allgemeine Mission / Sache unterstuetzen
2. konkrete Projekte finanzieren
3. Ressourcen fuer Umsetzung organisieren

Damit deckt das System sowohl:
- allgemeine gesellschaftliche Bewegung
- als auch konkrete lokale Umsetzung
ab.
