# Governance Core Model

## Kernfluss

Signal -> Anlassraum -> Dossier -> Runde -> Mandat -> Umsetzung -> Impact

## Signale
Relevanzhinweise aus Community, Feed, Journalismus, Event, Hinweis, Verwaltung.

## Anlassraeume
Kontextcontainer fuer Themen, Konflikte, Projekte und Events.

## Dossiers
Analytische Verdichtung eines oder mehrerer Anlassraeume.

## Runden
Deliberations- oder Abstimmungsraeume.

## Mandate
Formalisierte Uebergaenge in Beschluss / Auftrag / Projekt.

## Umsetzung
Operative Realisierung.

## Impact
Sichtbare Wirkung / Monitoring / Folgeprojekte.

## Leitregeln
- review-first
- publish-gated
- trust-separated
- funding-separated
- no auto publish
