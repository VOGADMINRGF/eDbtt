# Truth Guardrails

## Grundsatz

Das System erzeugt keine automatische Wahrheit.
Es zeigt:
- Quellen
- Gegenquellen
- Unklarheiten
- Konflikte
- offene Fragen

## Regeln
- keine ungepruefte Auto-Publikation
- keine Wahrheitslabels ohne Evidenz
- kritische Behauptungen nur mit ausreichender Quellenbasis
- anonyme Hinweise nie direkt publikationsfaehig
- Geld / Funding darf Wahrheit nicht beeinflussen
