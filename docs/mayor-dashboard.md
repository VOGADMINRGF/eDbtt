# Mayor Dashboard

## Ziel

Executive Surface fuer Buergermeister / Verwaltungsspitze.

## Kernbereiche
- Radar: Was bewegt die Gemeinde?
- aktive Anlassraeume
- kritische Konflikte
- laufende Events / QR-Raeume
- Dossiers in Bearbeitung
- Entscheidungsreife Themen
- Umsetzungs-/Monitoringstatus
- Funding / Matching / Community-Projekte

## Grundsatz
Nicht Klickibunti, sondern:
- Lagebild
- Priorisierung
- Handlungsoptionen
- Transparenz
