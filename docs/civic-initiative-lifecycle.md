# Civic Initiative Lifecycle

## Ziel

Community- und Buergerinitiativen sollen im selben Kernmodell laufen wie institutionelle Prozesse.

## Fluss
Signal -> Anlassraum -> Dossier -> Runde -> Unterstuetzung / Funding -> Umsetzung -> Impact

## Initiative kann entstehen durch
- Community Input
- Event
- journalistischen Anlass
- Hinweis
- Radar-Thema
- konkretes lokales Projekt

## Funding-Modi
- mission
- project
- resource
- hybrid
