# Municipality Operating Model

## Ziel

Kommunen / Verwaltungen sollen eDebatte operativ nutzen koennen, ohne eine Vollredaktion aufbauen zu muessen.

## Kernmodule
- Radar
- Anlassraeume
- Event-/QR-Integration
- Dossiers
- Verwaltungsmodus
- Monitoring

## Typische Fluesse
- Thema taucht im Radar auf
- Anlassraum wird manuell oder halbgestuetzt angelegt
- Feed / Quellen / Hinweise werden zugeordnet
- Event / Buergerabend fuehrt zu Inputs
- Dossier verdichtet
- Runde / weitere Konsultation
- Umsetzung / Monitoring

## Statusbeispiele
- community_driven
- administrative_review
- official_consultation
- approved
- in_implementation
- rejected
- monitoring
