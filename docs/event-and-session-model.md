# Event and Session Model

## Grundidee

Jedes Event / jede Sitzung / jeder Dialog kann ein eigener Anlassraum sein.

## Beispiele
- Buergerabend
- Ausschusssitzung
- Townhall
- Parteitag
- Verbandssitzung
- Kita-Termin
- B2B Workshop

## Fluss
Event -> QR / Fragen -> Anlassraum -> Dossier / Nachbereitung -> ggf. Runde / Umsetzung

## Plattformunterstuetzung
- Anlass / Agenda Vorschlaege
- Quellenabgleich
- aehnliche Dossiers / Anlassraeume
- Live-Input
- Nachbereitung
