# Voxy Production Pack v3

Repo-ready asset pack for the Voxy mascot.

## Included formats
- PNG (source-of-truth raster)
- WebP (web-optimized)

## Canonical asset directory
`apps/web/public/brand/voxy/`

## Recommended UI usage
- **Light mode:** place Voxy on white or very light neutral cards with a subtle border and soft shadow.
- **Dark mode:** keep the asset unchanged and place it on a dark navy/charcoal card with a slight glow or light border behind the card.
- Do **not** recolor or invert the mascot between modes.
- Keep the **VOG** pin on the viewer-right lapel and the **eDebatte** pocket wordmark unchanged.

## Asset map
- `voxy-neutral` – standard guide
- `voxy-thinking` – analysis / optional AI
- `voxy-check` – success / confirmation
- `voxy-hint` – important hint
- `voxy-welcome` – onboarding
- `voxy-presenting` – explanation / storytelling
- `voxy-open` – participation / openness
- `voxy-confident` – trust / authority
- `voxy-wave` – greeting
- `voxy-mini-avatar` – compact usage
